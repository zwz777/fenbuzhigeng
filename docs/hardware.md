# 后续硬件接入说明

## 推荐分层

第一阶段让电脑运行 YOLO，控制板只负责执行：

```text
电脑：摄像头、YOLO、动作策略
  | USB串口 / Wi-Fi
控制板：ESP32或树莓派
  | PWM / GPIO
执行器：电机驱动器、机械臂关节电机、水泵、继电器
```

不要把电机直接接到树莓派 GPIO。GPIO 只输出控制信号，电机需要独立的电源和驱动器。

## 第一批硬件

- USB摄像头；
- ESP32开发板或树莓派；
- 2WD底盘和带编码器的直流减速电机；
- 电机驱动板；
- 轻量机械臂；
- 水泵、软管、喷头和MOS管模块；
- 独立电池、降压模块、保险和总电源开关。

机械臂第一版可以使用成品舵机臂做动作验证。若改用独立电机，至少需要“电机、减速器、驱动器、编码器、限位开关”五类部件，不能只购买一个裸电机。

## 串口协议

控制端每行发送一条 UTF-8 JSON：

```json
{"type":"command","action":"move_left","duration_ms":250}
{"type":"command","action":"spray","duration_ms":300}
```

控制板执行后应返回：

```json
{"type":"ack","action":"spray","ok":true}
```

通信超时、数据格式错误或急停触发时，控制板必须停止底盘和水泵。

## 安全边界

- 只用清水和彩色水测试；
- 喷头默认关闭；
- 电机和水泵使用独立保险/限流；
- 设置物理急停；
- 机械臂设置软件角度限位和机械限位；
- 先在桌面和封闭区域测试，再考虑室外。
